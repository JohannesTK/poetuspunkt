# Põetuspunkt Pärnumaa – patsiendiregister

Ühe failiga veebirakendus (`index.html`) põetuspunkti patsientide arvestuseks.

**Andmed salvestatakse ainult brauseri localStorage'isse** sellel seadmel – neid ei saadeta kuhugi ega jagata teiste kasutajatega. Varukoopia tegemiseks ja teise seadmesse viimiseks kasuta päise andmebaasi-ikooni menüüd (eksport/import JSON).
